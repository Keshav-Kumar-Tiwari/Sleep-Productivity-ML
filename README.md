# 🛌 Sleep Productivity Predictor 📈

A Machine Learning project that predicts **productivity based on sleep hours** using a **Linear Regression** model.

## 📊 Dataset

The project uses the following dataset:

```text
sleep_productivity.csv
```

## 🛠️ Libraries Used

* 🐍 Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## ⚙️ Machine Learning Workflow

1. 📥 Loaded the dataset
2. 🧹 Preprocessed the data
3. ✂️ Split the data into training and testing sets
4. 📏 Scaled the features
5. 🤖 Applied Linear Regression
6. 📊 Evaluated the model using **R² Score**

## 📈 Model Performance

**R² Score:** ~0.66

This indicates that the model explains approximately **66% of the variation in productivity** based on the features used.
